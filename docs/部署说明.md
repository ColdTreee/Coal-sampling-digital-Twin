# 本地开发与部署

## Docker Compose

需要安装 Docker Desktop 并启动 Docker Engine。在仓库根目录执行 docker compose -f infra/docker-compose.yml up --build。

前端入口为 http://localhost:8080，API 文档为 http://localhost:8080/docs，健康检查为 http://localhost:8080/health。首次启动的管理员账号由 BOOTSTRAP_ADMIN_USERNAME 和 BOOTSTRAP_ADMIN_PASSWORD 设置，JWT_SECRET 与 PostgreSQL 口令也必须在共享或服务器部署时替换默认值。仅在本机演示环境使用默认配置。

停止服务时执行 docker compose -f infra/docker-compose.yml down。PostgreSQL 数据保存在 Compose 命名卷 postgres_data 中。

## 分离运行前后端

1. 在 backend 安装 Python 3.12 及依赖：python -m pip install -r requirements.txt。
2. 将 backend/.env.example 复制为 backend/.env，按本机 PostgreSQL 连接修改 DATABASE_URL。
3. 设置强 JWT_SECRET 和 BOOTSTRAP_ADMIN_PASSWORD，在 backend 运行 alembic upgrade head，再运行 uvicorn app.main:app --reload。
4. 在 frontend 运行 npm install，然后运行 npm run dev。Vite 将 /health 和 /api 代理至本地 8000 端口。

## 阶段一自测

在 backend 执行 pytest。测试覆盖阶段二到阶段五 API、角色权限、业务状态迁移、报文幂等、告警处置、CSV 审计和健康检查。Docker Compose 验收需要 Docker Engine。

## Playwright 端到端测试

先启动前后端并准备一个专用管理员测试账号，然后在 PowerShell 中设置 E2E_ADMIN_USERNAME、E2E_ADMIN_PASSWORD 和可选的 E2E_BASE_URL，再于 frontend 执行 npm run test:e2e。测试会创建带 PW 前缀的批次、设备、测点、规则、样品和报文，数据保留在当前数据库中。
